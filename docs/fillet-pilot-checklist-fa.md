## پیش‌نیاز پرود (فاز ۰ و ۱)

- [ ] دیپلوی موفق Runflare (UI فارسی در رویداد ترازو)
- [ ] متغیر `SCALE_API_KEY` روی سرور
- [ ] متغیر `PILOT_DEFAULT_SALE_PLU` با مقدار کد فروش فیله (مثلاً همان کد در seed)
- [ ] `npx prisma migrate deploy`
- [ ] `npm run db:seed`

## پاکسازی — شروع دستی از صفر

- [ ] `npm run db:reset-pilot:full` (کنسول Runflare در `/app`)
- [ ] **seed نزنید** — کالاها را خودتان از پنل «ثبت کالا» بسازید

فقط صفر کردن فاکتور با کالاهای آماده: `db:reset-pilot` + `db:seed`
